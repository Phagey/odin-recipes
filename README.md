# Recipe Website Project

This is a basic HTML project created as part of mys web development practice exercise. The website consists of a main index page that includes links to a few individual recipe pages.

## Project Overview

The goal of this project is to practice and demonstrate foundational HTML skills. The structure includes:

- A main `index.html` page with links to other recipe pages.
- Use of proper HTML elements such as headings, paragraphs, images, and links.
- Organizing files and directories (e.g., separate folders for images or recipe pages).

## Skills Demonstrated

By completing this project, I will have practiced and improved the following skills:

- Writing clean and semantic HTML
- Creating internal links between multiple HTML pages
- Structuring a basic website with multiple files
- Organizing project directories and resources

This project is part of my learning journey in front-end web development.
